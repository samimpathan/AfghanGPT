# Samim AI — د عبدالصمیم مرستیال

وړیا AI چټ اپ — لکه Muse / ChatGPT، خو د صمیم خپل. هر څوک کولای شي اکاونټ جوړ کړي او پوښتنې وکړي: پروګرامینګ، ویبسایټ، انګلیسي، او عمومي معلومات.

**مهم:** هېڅ شی خپور شوی نه دی — نه GitHub ته push شوی، نه Vercel ته deploy شوی. دا یوازې په دې کمپیوټر کې جوړ شوی دی.

## څه پکې شته؟

- **چټ** (`/`): لکه ChatGPT — کیڼ لور ته د چټونو لیست (نوی چټ، لټون، نوم بدلول، ړنګول)، په منځ کې پیغامونه، د کلمې په کلمه ځواب، د ودرولو (■) تڼۍ، بیا ځواب، کاپي، او کوډ بلاکونه د کاپي تڼۍ سره.
- **اکاونټ** (`/register`، `/login`): هر څوک اکاونټ جوړولای شي — هېڅ زده‌کوونکی شرط نشته، هېڅ بلنه نه غواړي. پاسورډ هېر شو؟ د بیا جوړولو لینک په ایمیل کې راځي.
- **ژبې او رنګ**: پښتو (اصلي)، انګلیسي، دري — پښتو/دري کې لیکنه ښي څخه کیڼ ته ده. تور او روښانه حالت شته.
- **ترتیبات** (`/settings`): ژبه، رنګ، ماډل معلومات، تاریخچه پاکول، اکاونټ، وتل.
- **زموږ په اړه** (`/about`): Samim AI څه دی، بنسټګر صمیم څوک دی.
- **خوندیتوب**: که څوک porn، adult یا sexy پوښتنه وکړي، ځواب دا دی: «دا محتوا نه لرو. نور هر رقم پوښتنه کولای شې — پروګرامینګ، ویبسایټ، انګلیسي او نور». نور هر رقم پوښتنه حل کېږي.

## AI څنګه کار کوي؟

- **اصلي AI:** Google Gemini — ماډل `gemini-3-flash-preview`، وړیا tier. ځوابونه په سرور کې جوړېږي (`src/app/api/chat/route.ts`)، او کېلي یوازې په سرور کې ده — په براوزر کې هېڅکله نه ښکاري.
- **آف‌لاین حالت:** که کېلي نه وي، اپ په وړیا آف‌لاین دماغ سره ځواب ورکوي (`src/lib/offlineBrain.ts` — سلام، DevConnect، بنسټګر، HTML/CSS/JS/Python/C++/Java، انګلیسي درسونه). ځواب په ښکاره توګه «آف‌لاین حالت» لیکل شوی وي — هېڅکله نه وايي چې دا Gemini دی.

## ۱ ګام — Supabase میګریشن چلول (یوازې صمیم)

دا ګام اوس **نه دی شوی** — ته یې پخپله کوې:

1. Supabase Dashboard خلاص کړه (هغه پروژټ چې DevConnect یې کاروي).
2. کیڼ لور ته **SQL Editor** → **New query** وټاکه.
3. دا فایل خلاص کړه: `supabase/ai-001.sql` — ټول متن یې کاپي کړه او په SQL Editor کې یې پېسټ کړه.
4. **Run** ووهه.
5. د تایید لپاره دا دوه کرښې هم په SQL Editor کې وچلوه:
   ```sql
   select count(*) from public.ai_chats;
   select count(*) from public.ai_messages;
   ```
   دواړه باید `0` وښيي، بې تېروتنې.
6. دا میګریشن یوازې دوه **نوي** جدولونه جوړوي (`ai_chats`، `ai_messages`) — د DevConnect هېڅ جدول ته لاس نه ورکوي. هر کارن یوازې خپل چټونه لیدلای شي (RLS پالیسۍ).

## ۲ ګام — وړیا Gemini کېلي اخیستل (یوازې صمیم، وړیا، بې کارت)

1. په Wi-Fi کې دا پاڼه خلاص کړه: **aistudio.google.com**
2. د خپل Gmail سره ننوځه: **samimpatan8@gmail.com**
3. **Get API key** وټاکه → **Create API key** وټاکه.
4. کېلي کاپي کړه. **هېڅکله یې په چټ کې مه لېږه** — کېلي یوازې په خوندي ځای کې وساته.
5. په دې فولډر کې `.env.local` فایل جوړ کړه (د `.env.local.example` څخه یې کاپي کړه) او دا درې کرښې پکې ولیکه:
   ```
   NEXT_PUBLIC_SUPABASE_URL=...
   NEXT_PUBLIC_SUPABASE_ANON_KEY=...
   GEMINI_API_KEY=ستا_کېلي_دلته
   ```
   د Supabase دوه ارزښتونه له `~/workspace/devconnect-app/.env.local` څخه اخیستل کېږي. `.env.local` هېڅکله GitHub ته نه ځي.

## ۳ ګام — په خپل کمپیوټر کې چلول

```bash
cd samim-ai-web
npm install
npm run dev
```

بیا براوزر کې خلاص کړه: **http://localhost:3000**

## خپرول (Deploy) — لا نه دی شوی

د خپرولو لپاره د صمیم جلا اجازه پکار ده. کله چې اجازه راکړې، دا به په Vercel کې خپور شي، او `GEMINI_API_KEY` به د Vercel په Environment Variables کې کېښودل شي — په کوډ کې هېڅکله نه.

## که څه خراب شي؟

- که اکاونټ جوړ نه شي: لومړی وګوره چې `ai-001.sql` دې چلولې ده، او `.env.local` دې سم دی.
- که ځواب «آف‌لاین حالت» وي: دا پدې مانا ده چې `GEMINI_API_KEY` نشته یا سمه نه ده — ۲ ګام بیا وګوره.
- که پاڼه خلاصه نه شي: `npm run dev` بیا چلوه، او ډاډه شه چې پورټ 3000 خالي دی.
